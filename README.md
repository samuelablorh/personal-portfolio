# Personal Portfolio

A multidisciplinary personal portfolio built with **Next.js, TypeScript, Tailwind CSS and Sanity CMS**. Showcasing projects, skills and professional experience across web development, data science, artificial intelligence and other technology disciplines.

## Tech Stack

- Next.js
- TypeScript
- React
- Tailwind CSS
- shadcn/ui
- Sanity CMS
- GROQ
- Markdown
- GitHub
- Vercel
